- **선착순 매크로 (First-come Macros)**

  Automating time-critical tasks like ticketing, limited sales, and reservations.

- **업무 자동화 (Work Automation)**
  반복 업무를 줄여주는 데스크톱 / 웹 기반 자동화 도구 제작
  Building desktop & web automation tools to reduce repetitive work.

  필요한 데이터를 안정적으로 수집하고 정리하는 크롤러 개발
